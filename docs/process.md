# Процесс работы команды Team 3

## Definition of Ready (DoR)

Задача готова к работе, если:

- [ ] есть понятное описание и цель;
- [ ] определены критерии приёмки;
- [ ] проставлены приоритет и размер;
- [ ] назначен исполнитель;
- [ ] понятны зависимости от других задач.

## Definition of Done (DoD)

Задача считается выполненной, если:

- [ ] реализованы все критерии приёмки;
- [ ] код прошёл ревью (минимум 1 аппрув);
- [ ] CI зелёный (линтеры, типы, тесты);
- [ ] обновлена документация (при необходимости);
- [ ] задача переведена в статус `Done` на доске.

## WIP-лимит

- Не более **2 задач** в статусе `In progress` на человека.
- Задача не берётся в работу, если она не проходит DoR.

## Ветки и коммиты

- `main` — стабильная ветка, защищена.
- Ветки задач: `feature/<номер>-<краткое-описание>`, `fix/<номер>-<...>`.
- Коммиты: Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).

## Ревью

- Минимум один аппрув перед merge.
- Конфликты решает автор PR.
- Обратная связь — по факту, без перехода на личности.
