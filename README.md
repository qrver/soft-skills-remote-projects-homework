# ChronoStore — интернет-магазин часов

**ChronoStore** — учебный командный проект: интернет-магазин наручных часов с каталогом, корзиной, онлайн-оплатой и личным кабинетом. Проект ведётся распределённой командой **Team 3** и полностью управляется через **GitHub Projects**.

[![Repo](https://img.shields.io/badge/Repo-soft--skills--remote--projects-181717?logo=github)](https://github.com/qrver/soft-skills-remote-projects-homework)

## 1. О проекте

Магазин позволяет подобрать часы по бренду, механизму, полу и цене, оформить заказ с доставкой и оплатить его онлайн. За ассортимент и заказы отвечает админ-панель.

**Ключевые возможности**

| Блок | Возможности |
|------|-------------|
| Каталог | Фильтры, сортировка, поиск, карточка товара |
| Заказ | Корзина, оформление, онлайн-оплата, статус заказа |
| Аккаунт | Регистрация, вход, история заказов |
| Админка | Товары, категории, цены, остатки |
| Инфраструктура | CI, Docker, деплой staging/prod |

**Технологии**

- **Frontend:** Next.js (React + TypeScript)
- **Backend:** Java 21 + Spring Boot, PostgreSQL
- **Инфраструктура:** Docker, GitHub Actions, GitHub Projects

## 4. Правила коммуникации и обмена информацией

### Формальная коммуникация

1. **Единый основной канал** — все важные договорённости только в общем чате команды.
2. **Асинхронность по умолчанию** — решения фиксируем текстом, а не устно.
3. **Регламент ответа** — в рабочее время отвечаем в течение ~2 часов; если заняты — ставим статус.
4. **Один источник правды** — статус задач ведётся на [доске GitHub Projects](https://github.com/users/qrver/projects/4/views/1).
5. **Блокировки сообщаем сразу** — если задача мешает другим, пишем в чат немедленно.
6. **Дедлайны** — о риске срыва срока предупреждаем минимум за сутки.
7. **Созвоны** — короткие дейли по необходимости, решения после них дублируем текстом.
8. **Ревью** — минимум один аппрув перед merge; обратная связь по факту, без перехода на личности.

### Неформальное общение

9. **Живое общение** — мемы, шутки и общий чат приветствуются: это снижает напряжение.
10. **Неформальные созвоны** — периодически общаемся вне задач, чтобы лучше понимать друг друга.
11. **Уважение ко времени** — вне рабочего времени никто не обязан отвечать срочно.
12. **Взаимопомощь** — у каждого бывают загрузки, поэтому помогаем и подхватываем задачи.

## 5. Управление проектом

Вся работа ведётся на доске **GitHub Projects**:

- **Доска:** https://github.com/users/qrver/projects/4/views/1
- **Статусы:** `Todo` → `In progress` → `Done`
- **Поля задач:** Приоритет (P0–P2), Размер (XS–XL), Исполнитель, Начало / Дедлайн
- **Вехи (milestones):**
  - `M1 — Discovery & Design`
  - `M2 — MVP: каталог и корзина`
  - `M3 — Оформление заказа и оплата`
  - `M4 — Аккаунты, админка и релиз v1.0`

### Процесс работы

1. Задача готова к работе, когда есть описание и критерии приёмки (**Definition of Ready**).
2. На человека одновременно не более 2 задач в статусе `In progress` (WIP-лимит).
3. Задача переводится в `Done` после ревью и прохождения CI (**Definition of Done**).
